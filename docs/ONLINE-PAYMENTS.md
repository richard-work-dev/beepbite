# Online payments

Online card processing is not supported by the current serverless product.
The former optional provider integration depended on the retired backend and
is not included in Lambda builds. Do not configure processor credentials here
or send card data to BeepBite.

For remote orders, the restaurant and customer should agree on an external
payment method. Staff can record the tender in the POS once payment has been
received. BeepBite does not collect, store or process card details.

This page is retained because older documentation links may still point here;
it is not an implementation or setup guide for an active payment feature.
